# BMI Program

Barnaamijkani wuxuu xisaabiyaa BMI-ga qofka iyadoo la gelinayo miisaanka kiiloogaraam (kg) iyo dhererka mitir (m).

## Formula

BMI = Miisaanka (kg) / Dhererka (m)²

Barnaamijku wuxuu isticmaalaa formula-ga kg iyo mitir. Formula-ga pounds-ka ee `* 703` kuma jiro.

## Qaybaha BMI

- Ka yar 18.5: Underweight
- 18.5 ilaa 25: Optimal weight
- Ka weyn 25: Overweight

## Xaqiijinta gelinta

- Haddii miisaanka ama dhererku madhan yahay ama aanu tiro ahayn, barnaamijku wuxuu muujiyaa:  
  `Invalid input! Please enter a numeric value.`
- Haddii miisaanka ama dhererku eber yahay ama taban yahay, wuxuu muujiyaa:  
  `Invalid input! Weight and height must be positive.`

Natiijada BMI-ga iyo qaybta miisaanka waxaa lagu muujiyaa fariin popup ah.

## Sida loo isticmaalo

1. Geli miisaankaaga kg ahaan.
2. Geli dhererkaaga mitir ahaan.
3. Riix **Calculate** si loo xisaabiyo BMI-ga.
4. Riix **Exit** si aad barnaamijka uga baxdo.
